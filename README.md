# Jira для FastAction

[English](README.en.md)

Задачи Jira в панели [FastAction](https://github.com/kasaley/fastActionVersions): список по
вашим фильтрам, описание и комментарии прямо в челке, центр уведомлений об изменениях.

![Вкладка Jira](https://github.com/kasaley/fastActionVersions/raw/main/docs/screenshots/tab-com.fastaction.jira.png)

## Что умеет

- **Задачи по вашим фильтрам.** Несколько фильтров с переключением; JQL можно написать
  руками, собрать в конструкторе, взять из сохранённых фильтров Jira или получить
  из ссылки на доску — исполнители из заголовка доски переносятся вместе с ней.
- **Задача целиком в панели**: описание с разметкой Jira, приведённой к читаемому виду,
  и последние комментарии. Оттуда же — переход в браузер и копирование номера или ссылки.
- **Уведомления о новых задачах** по каждому фильтру и об изменениях в тех, за которыми
  вы следите. Нажатие на уведомление открывает саму задачу.
- **Центр уведомлений** внутри вкладки: что произошло, с отметками о прочтении.
- **Пошаговая настройка**: адрес, способ входа, токен — с проверкой на каждом шаге.
  Если Jira откажет, мастер вернёт на тот шаг, который в этом виноват.

## Установка

**Настройки → Плагины** в FastAction: плагин есть в каталоге, ставится оттуда в одно
нажатие. Вручную — скачайте архив из [релизов](../../releases) и выберите его в
**Настройки → Плагины → Установить плагин…**.

При первом запуске плагин спросит адрес вашей Jira и токен. Токен хранится в связке
ключей macOS, а не в файлах плагина.

## Что плагин просит и зачем

| Разрешение | Зачем |
| --- | --- |
| `network` | только адрес вашей Jira — тот, который вы вписали в настройках плагина |
| `secrets` | хранить токен в связке ключей |
| `clipboard` | копировать номер задачи и ссылку |
| `notifications` | сообщать о новых задачах и изменениях |
| `openURL` | открывать задачу в браузере |

Ни одного другого адреса плагин не увидит: песочница разрешает ровно тот хост, что
записан в манифесте, а там стоит `$setting:site` — адрес из ваших же настроек.

## Разработка

Нужен только Python 3.

```sh
tools/fastplugin check     # манифест разобран и осмыслен
tools/fastplugin stamp     # обязательно после каждой правки plugin.js
tools/fastplugin package   # собрать архив и посчитать sha256
tools/fastplugin release   # тег, релиз и запись для каталога
```

`stamp` обязателен: приложение сверяет sha256 скрипта с тем, что записано в манифесте,
и отказывается запускать плагин, если они разошлись. Так плагин, отредактированный
после установки, не сможет воспользоваться разрешениями, которые вы дали раньше.

Как устроены плагины вообще — [руководство автора](https://github.com/kasaley/fastActionPlugins/blob/main/docs/PLUGINS.md).
Каталог, куда попадают записи о релизах, — [fastActionPlugins](https://github.com/kasaley/fastActionPlugins).
